# Super-Store-Sales-PowerBI
Interactive Super Store Sales Analysis Dashboard built using Power BI, DAX, and Power Query to analyze sales, profit, regions, segments, categories, shipping modes, and time-based trends.
The objective of this project is to transform raw sales data into meaningful business insights that can support data-driven decision-making.

1.🎯 Objectives

Analyze overall sales and profit performance
Identify top-performing regions and cities
Compare sales across customer segments
Analyze product category and sub-category performance
Understand different shipping modes
Track sales and profit trends over time
Create an interactive dashboard using Power BI

5.🔍 Key Insights

The Consumer segment contributes the highest sales.
The East region shows strong overall sales performance.
Standard Class is the most frequently used shipping mode.
Sales and profit vary significantly across product categories and sub-categories.
Time-based analysis helps identify changes in sales and profitability throughout the year.
